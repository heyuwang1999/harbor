# 海港餅店 顧客常見問題

本文件為示範用虛構內容。

## 營業時間

各分店營業時間為星期一至星期六上午七時至晚上八時，星期日及公眾假期上午八時至晚上六時。農曆新年初一至初三休息。

## 分店地址

- 將軍澳店：將軍澳運亨路一號地舖
- 觀塘店：觀塘開源道八十八號地下三號舖
- 中環店：中環德輔道中一百二十號一樓

## 訂造蛋糕

訂造蛋糕須於取貨日前最少三個工作天下單，並繳付五成訂金。相片蛋糕及立體造型蛋糕須預留五個工作天。訂單一經確認，如需更改款式，請於取貨日前兩個工作天通知門市。

## 送貨服務

港島、九龍及新界指定地區提供送貨服務，滿五百港元免運費，未滿五百港元收取六十港元運費。送貨時段為上午十時至下午六時，未能提供指定時間送達。離島地區暫不提供送貨。

## 退款及更換政策

如貨品在取貨當日出現品質問題，請於二十四小時內連同收據到原門市辦理退款或更換。訂造蛋糕因屬個人化製作，除品質問題外恕不接受退款。

## 食物敏感源資料

所有麵包及蛋糕均在同一廚房製作，可能含有或接觸到小麥、雞蛋、奶類、大豆及果仁。對食物敏感的顧客請於購買前向店員查詢。我們無法保證產品完全不含任何敏感源。

## 素食及無麩質選擇

我們提供三款純素麵包（全麥核桃、黑芝麻、南瓜籽），每日下午兩時後在將軍澳店及觀塘店供應。暫時未有無麩質產品。

## 會員積分

消費滿一港元可獲一分，一百分可兌換港幣十元現金券。積分有效期為十二個月。會籍及積分不可轉讓。

## 團體及公司訂單

五十件以上的團體訂單可享九折，請於取貨日前五個工作天透過門市或電郵落單，並提供公司發票資料。

## 付款方式

門市接受現金、八達通、信用卡、支付寶及微信支付。送貨訂單須以電子方式預先付款。
