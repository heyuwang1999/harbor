# 海港餅店 薪酬級別（管理層限閱）

本文件為示範用虛構內容，僅供管理層參閱。此文件用於示範文件層級權限：一般員工及訪客不應在搜尋結果中看到本文件的任何內容。

## 職級與月薪範圍

| 職級 | 職位 | 月薪範圍（港幣） |
|---|---|---|
| B1 | 見習麵包師 | 14,000 – 16,500 |
| B2 | 麵包師 | 16,500 – 21,000 |
| B3 | 高級麵包師 | 21,000 – 27,000 |
| S1 | 門市助理 | 13,500 – 15,500 |
| S2 | 門市主管 | 15,500 – 19,000 |
| M1 | 分店經理 | 22,000 – 30,000 |
| M2 | 區域經理 | 32,000 – 45,000 |

## 調薪週期

每年四月進行一次全面薪酬檢討，調幅參考通脹、公司業績及個人表現評級。表現評級為「優秀」者，調幅上限為百分之八；「達標」者為百分之四。

## 花紅

年終花紅相等於一個月基本薪金，須於發放日仍在職方可獲得。分店經理另設季度績效花紅，上限為季度基本薪金的百分之十，與分店營業額及食物成本控制掛鈎。

## 招聘薪酬指引

新聘員工薪金原則上不得超過同職級現有員工的中位數，如有例外須經董事總經理批准。
