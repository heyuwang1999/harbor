# 海港餅店 員工手冊

本文件為示範用虛構內容，並非法律意見。

## 法定假日

僱員連續受僱滿四星期，而每星期工作最少十八小時，即可享有法定假日。法定假日當日如須輪值上班，公司會在該日前後三十天內安排補假，並由分店經理在排班表上註明。

## 有薪年假

僱員每服務滿十二個月，可享有有薪年假。首兩年每年七天，第三年起每年增加一天，上限為十四天。年假須於年度結束後三個月內放取，未放取的年假不會自動折現。

申請年假須於出發前最少十四天在人事系統提交，並取得分店經理批准。旺季（農曆新年前兩星期、中秋節前一星期）原則上不批年假。

## 病假與醫生證明

僱員因病缺勤連續四天或以上，並已累積足夠有薪病假日數，可獲發疾病津貼，金額為平均每日工資的五分之四。

申請病假津貼必須提交註冊醫生簽發的醫生證明書，證明書須列明缺勤日期及不適宜工作的原因。只請一天病假亦須於當日上班時間前一小時通知分店經理，並於復工當日補交醫生紙。

## 強積金供款

僱主及僱員各按有關入息的百分之五作出強積金供款。月薪低於七千一百港元的僱員毋須作出僱員部分供款，但僱主仍會供款。新入職僱員會在受僱首六十日內獲安排登記。

## 颱風及暴雨安排

如天文台懸掛八號或以上颱風信號，或發出黑色暴雨警告，所有門市暫停營業，非必要員工毋須上班。信號取消後，如距離當日營業結束尚有兩小時或以上，員工須於兩小時內返回工作崗位。

因惡劣天氣而未能上班的時數，不會從年假或工資中扣除。

## 試用期與通知期

新入職員工試用期為三個月。試用期內任何一方終止僱傭合約，須給予七天通知或代通知金；試用期首月內則毋須通知。

試用期滿後，任何一方終止合約須給予一個月通知或代通知金。

## 加班與補假

加班須事先獲分店經理批准。經批准的加班時數以補假形式補償，補假須於三個月內放取。全職員工每週標準工時為四十四小時。

## 產假與侍產假

合資格女性僱員可享有連續十四星期產假。合資格男性僱員可享有五天侍產假，可分開放取，但須於嬰兒出生日前四星期至出生後十四星期內放取。

## 員工福利

- 全職僱員及其直系家屬可享門市貨品七折優惠，每月上限一千港元。
- 公司為所有全職僱員提供團體醫療保險，涵蓋門診、住院及牙科基本檢查。
- 每年可申請最多八千港元培訓資助，詳見報銷及開支政策。

## 制服與儀容

前線員工須穿著公司提供的制服及防滑鞋。廚房員工必須佩戴髮網及口罩。制服每年更換兩套，如因損耗需額外更換，須向分店經理申請。
