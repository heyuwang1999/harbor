# 海港餅店 報銷及開支政策

本文件為示範用虛構內容。

## 適用範圍

本政策適用於所有全職及兼職僱員因公務而支出的費用。所有報銷必須附上正本收據或電子收據，並在系統中選擇正確的開支類別。

## 交通費

因公務往返分店、供應商或培訓地點的交通費可全數報銷，包括港鐵、巴士、小巴及的士。乘搭的士須在備註欄說明原因，例如夜間運送貨品或攜帶大型物資。

交通費報銷須於支出日起一個月內提交，逾期恕不受理。

## 手機及通訊津貼

分店經理及需要使用公司系統的前線主管，每月可報銷最高五百港元手機費用，須附上電訊商賬單。兼職員工不適用。

## 培訓資助

每名全職僱員每年可申請最多八千港元培訓資助，課程須與職務相關，例如食品安全、烘焙技術或管理課程。

申請須在報名前提交，並取得部門主管批准。完成課程後須提交結業證書及收據，方可發放資助。如僱員在完成課程後六個月內離職，公司保留追討資助的權利。

## 招待及客戶開支

招待供應商或企業客戶的餐飲開支，每人每次上限三百港元，並須列明出席者姓名及公司。酒精飲品不可報銷。

## 審批權限

- 一千港元以下：分店經理批准
- 一千至五千港元：營運總監批准
- 五千港元以上：董事總經理批准

## 報銷流程

1. 在系統填寫報銷申請，上載收據圖片。
2. 直屬上司於三個工作天內審批。
3. 財務部於每月十五日及月底兩次過數，款項存入員工出糧戶口。

如申請被退回，員工須於七天內補交資料，否則申請將自動取消。
